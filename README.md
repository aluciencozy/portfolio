# Alex Cosentino Portfolio

My personal developer portfolio, designed around my terminal and Neovim setup
with the Catppuccin Mocha theme.

The site opens with a simulated Zsh boot, types `nvim .`, and transitions into
an accessible portfolio workspace with projects, experience, contact details,
Vim-inspired navigation, and a simulated terminal.

Built with Next.js, TypeScript, Motion, and Vercel.

## Local development

```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).

All terminal and Neovim commands are simulated in the browser. No shell commands
are executed.
